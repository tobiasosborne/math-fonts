# Comic Sans Math — future direction

The user supplied [this original style-guide PNG](style-guide.png) from
Downloads on 2026-10-29 for later consideration: Comic Sans mathematics
imagined with the typographic care of Hoefler and Frere-Jones.

The sheet is an unofficial project concept, not a foundry-authored asset or
endorsement. Keep its friendly drawing, script-size clarity, radical/large
operator ambitions and whole-family presentation as future design evidence.
Its equations, coverage and construction annotations are not technically
validated; any real curve handles must be calculated from actual vectors.

This is not the active font campaign. Finish the Baskerville pipeline and
working math package first. A later Comic Sans project would need its own
approved unified master, finite coverage contract and rendering tests using
the proven pipeline. The source image is retained unchanged with dimensions
and SHA-256 in [provenance](provenance.json).
