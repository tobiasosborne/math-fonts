# Authored arrow family v1

Use `sources.json` for the corrected 34-glyph family. Shared geometry and exact
semantic scope are documented in [math-arrow-grammar.md](../../../docs/math-arrow-grammar.md).

- `grid.svg`: enlarged forms plus 10pt/7pt/5pt rows; no script-size compensation.
- `grid-guides.svg`: optional separate working-size axis guides.
- `metrics.json`: contours, areas, bounds, common parameters and solved joins.
- Each role directory: real cubic/straight filled outlines in `curves.json`.
- `preclip-draft/`: preserved, rejected initial double-shaft join experiment.

These are provisional authored design units derived from the valid unified-root
arrow's visual direction. They are not raster fits, accepted font designs,
MATH assemblies, hook arrows or successive two-head arrows. Seven geometry and
actual CFF/MATH compilation tests pass; optical and engine acceptance are separate.
