# Baskerville mathematics

Our first north star is a consistent, thematically unified mathematics package
for Baskerville, with core LaTeX mathematics, `amsmath` layouts and AMS symbols.
Continue the accepted Greek design through this pipeline:

**Baskerville references → one unified design image → specimen crops → faithful
glyph enlargements → measured local tracing → optical/font engineering → real
mathematical typesetting.**

Everything starts from the unified design image. Derived sheets and individual
glyphs share its version and visual authority; they are not independent designs.

Licensed under [GNU AGPL v3](LICENSE); see [third-party notices](NOTICE.md).
The public repository contains the current pipeline and generated design
evidence. Commercial reference fonts/specimens, private proofs and the old
backup remain local. Historical links below may require the original workspace.

The present deliverable is a design pipeline and successful outline study,
not a complete compiled math family. Broader glyph coverage, optical drawing,
shared metrics and OpenType MATH engineering remain ahead. Source text fonts
remain user-supplied dependencies.
